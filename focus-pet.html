The problem

I wanted a gentle reminder to step away from social media and return to what I meant to do. Focus Pet explores how a familiar desktop companion can make that reminder feel encouraging.

Small, adjustable nudges

The first version includes a customizable animal, kind prompt styles, personal phrases, and a 45-minute focus / 15-minute break routine. A five-minute snooze and quiet or leisure settings give the user room to adjust how and when prompts appear.

Staged visual reminders make the companion part of the desktop experience, while customization allows the tone to feel more personal.

The technical decisions

  • Native desktop behavior. SwiftUI provides the macOS application interface.
  • Preferences stay local. Settings are saved locally by macOS.
  • Privacy is part of the first version. Screen awareness is off by default. The supplied README states that this version does not collect or upload screen data.
  • Give users control over the interruption. Snoozing and quiet settings allow reminders to adapt to the moment.

What this version explores

This project connects my interest in building useful tools with questions about attention and behavior. It is an exploration of supportive reminder design; I have not established that it reduces screen time or improves productivity.

The supplied README documents a local macOS build. Automatic social media detection is not claimed for this version.
