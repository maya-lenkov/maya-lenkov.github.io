The problem

A task list tells me what I need to do, but not where it fits. I wanted a planner that could work around real commitments and improve its time estimates from what actually happens.

From a list to a workable plan

The app accepts one task per line, with optional durations and locations. Tasks remain editable before scheduling. The planner works around existing timed Google Calendar events, protects lunch and dinner breaks, and keeps travel directly before the associated task.

The technical decisions

  • A direct calendar connection. Google OAuth connects to the signed-in account’s primary Google Calendar.
  • Useful without a model key. An on-device list parser supports task entry; optional OpenRouter integration provides AI task extraction.
  • Learn from actual durations. Local records of completed task durations inform future defaults.
  • Make scheduling constraints explicit. Edited times act as earliest start times, with conflicts pushing the task later rather than silently overlapping another commitment.

Scope and direction

The supplied README documents a native SwiftUI version of an earlier Python planner. Local planner state stores duration learning and travel memory. The broader goal is to make personal planning more realistic and help me understand where my time goes.

This portfolio does not claim a completed trend analytics dashboard or measured productivity improvement.
